# Contingency Command — Public Builds

Public Windows build downloads for **Contingency Command**, developed by
Flamage Studios.

Compiled game packages and update metadata will be distributed through this
repository's Releases page. This repository contains distribution information;
it does not contain the game's development source.

No game build has been published here yet. Launcher integration is in
preparation. Download instructions will accompany the first published build.

## Build records

Each published build should identify its BuildID and include release notes,
the compiled ZIP and its checksum. Signed update metadata accompanies builds
intended for the launcher. Publishing a new development build does not
automatically promote it to the ordinary Public update channel.

GitHub's automatically generated source-code archives contain this
distribution repository's files, not an installable copy of the game. Use
the explicitly attached game ZIP when a release becomes available.
